# Tài nguyên và Thông tin Test (Tạm thời)

Thư mục `temp` này và file này lưu trữ các thông tin, tài khoản, và dữ liệu để bạn dễ dàng copy/paste trong quá trình test hệ thống. Khi nào dự án hoàn thiện, bạn có thể xoá toàn bộ thư mục `temp` này.

## 1. Thông tin Máy chủ (Server)
- **Local URL**: [http://localhost:3000](http://localhost:3000)
- **Lệnh chạy server**: `npm run dev`

## 2. API & Tài liệu (Swagger)
- **Swagger API Docs**: [http://localhost:3000/api-docs](http://localhost:3000/api-docs)

## 3. Dữ liệu Test Tài khoản (Khuyên dùng)
Bạn có thể dùng các thông tin dưới đây để đăng ký thử nhanh chóng:

**Tài khoản 1:**
- **Tên đăng nhập**: `admin_test`
- **Email**: `admin@gmail.com`
- **Mật khẩu**: `123456`
- **Họ tên**: `Nguyễn Văn Quản Trị`
- **Số điện thoại**: `0912345678`
- **Địa chỉ**: `Hà Nội`

**Tài khoản 2:**
- **Tên đăng nhập**: `user_01`
- **Email**: `user01@gmail.com`
- **Mật khẩu**: `abcdef`
- **Họ tên**: `Trần Khách Thuê`
- **Số điện thoại**: `0987654321`
- **Địa chỉ**: `Hồ Chí Minh`

## 4. Dữ liệu Test Phòng trọ
*Dành cho tính năng thêm phòng trọ (sau này):*
- **Tên phòng**: `Phòng 101` hoặc `Studio 01`
- **Giá phòng**: `3000000`
- **Diện tích**: `25`
- **Loại phòng**: `Studio` hoặc `Phòng đơn`
- **Trạng thái**: `Available` hoặc `Occupied`
